# Changelog

## 0.3.0 — 2026-11-06

Add live Program annotation with pen, highlighter, whole-stroke eraser, per-page/frame undo/redo, color/width controls, pointer-centered zoom and bounded panning. Render higher-resolution rotated/cropped PDFs as zoom changes. Freeze local video with the displayed frame timestamp; retain snapshots and annotation histories separately from source files. Export sRGB PNG handouts with the Smixx Stream logo bottom left and filename plus page/time bottom right. Live ink appears in clean Program and recordings through the common renderer. Fix preview input mapping when the window adds letterboxing.

## 0.2.0 — 2026-11-06

Add local Program recording to H.264/AAC MP4 with independent Program audio consumption, elapsed time, Stop & Save, reveal-in-Finder, failure reporting, non-overwriting finalization and finish-before-quit. Preview/display/recording share a common composition renderer. Add an explicit audio-disabled preview banner and annotation specification with the required bottom-left filename plus page/time PNG footer. Annotation tools and PNG export remain specified, not implemented.

## 0.1.0 — 2026-11-05

Initial engineering alpha. Native teaching studio with four visual slots, PDF navigation, local media transport, window/display/camera adapters, clean Program presentation, two layouts and Desktop-derived six-source audio mixing. Includes separate settings, source reconnection, pause slate, input overlap checks and shared-driver ownership candidate.

Live capture/device/meeting/TV acceptance and automatic A/V synchronization remain open. Integrated Cast, direct AirPlay streaming and virtual camera are not included. Local build is ad-hoc signed; no production driver installer or public release is provided.
